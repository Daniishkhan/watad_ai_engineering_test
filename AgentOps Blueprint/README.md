# AgentOps Blueprint

This folder contains the optional add-on assessment submission for the Procurement RFQ Agent architecture exercise.

## Review path

Start with the completed submission:

```text
Danish_Khan_AgentOps_Blueprint_Submission.md
```

The original assessment materials are kept under `docs/`, and the machine-readable sample records are under `data/`.

## Notes

- This assessment asks for an architecture package, not runnable code.
- The design keeps external supplier communication behind explicit human approval.
- The source package constraints and failure cases are referenced directly in the submission.
